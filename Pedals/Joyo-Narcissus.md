# Joyo Narcissus (R-22)

Chorus pedal — not a reverb. (Named similarly to Joyo's reverb line, but this one is modulation only.)

## Knobs
- **Width**: Width of the chorus modulation
- **Depth**: Intensity of the chorus modulation
- **Rate**: Speed of the chorus modulation

## Mode switch
- **Vintage**: Classic, rich analog-style chorus character
- **Modern**: More aggressive/synthetic chorus voicing — gets warbly and pitch-wobbly at high Depth/Rate, useful for obvious "wet" chorus moments rather than a subtle sheen

## Notes for patch-building
- Last pedal before the GP-5 in the board order — layers on top of (or instead of) the GP-5's own MOD module. Don't run both at heavy settings at once; pick one as the primary chorus voice per patch to avoid mud.
- Vintage mode + low Depth/Rate is the general-purpose "light chorus underneath everything" choice, in line with the light-touch MOD default used across GP-5 patches.
- Modern mode is for songs specifically known for a drenched/obvious chorus tone.
