# Donner White Tape (Stereo Tape Delay)

Analog-circuit stereo delay voiced like a tape echo, with wow, flutter and bass drop-off on the repeats. Optional on both the guitar and bass Full Boards (added 2026-10-16), as an either/or with the Joyo American Sound. Michael says which one a build uses.

## Knobs
Two identical rows, one per channel. Top row = left channel, bottom row = right channel.
- **Level**: Delay (echo) level. Fully counterclockwise = dry signal only.
- **Time**: Delay time, 25ms to 1000ms.
- **Feedback**: Repeats. Fully counterclockwise = one repeat. Fully clockwise = infinite feedback (self-oscillation).

No toggle switches. No tap tempo.

## Jacks
- Input L / R (1/4" mono each). Mono input L can feed a stereo output.
- Output L / R (1/4" mono each).

## Footswitch
- Engages/bypasses the pedal. True bypass. Analog dry path when engaged.

## Power
- 9V DC, 100mA, center negative. No battery.

## Notes for patch-building
- Board position (Michael, 2026-10-16): **after the GP-5**, the last pedal on the board.
  - Guitar: ... → Narcissus → GP-5 → **White Tape**.
  - Bass: ... → Narcissus → GP-5 → **White Tape** → DC210XLT FX return.
- Michael's rig is mono, so only the **top row (left channel)** is used. Write up Level/Time/Feedback for the top row and say the bottom row is unused.
- It sits after the GP-5's reverb, so the repeats carry the reverb with them. Good for ambient/worship wash. For tight parts, keep Level low or the GP-5 reverb light.
- It's a second delay, independent of the GP-5's DLY block. Main uses:
  - Stack two delay times: e.g. GP-5 dotted eighth + White Tape quarter note, or GP-5 slapback + White Tape lead echo.
  - Take a lead delay off CTL to free a CTL slot. Its own footswitch handles it.
- No tap tempo or sync. Time is set by ear on the knob, so write the target in ms and as a note value, and tell Michael to dial it in against the track. Slap, solo echo and ambient layers tolerate this. A tight dotted eighth at a fast tempo is better left on the GP-5's DLY.
- Board knobs stay fixed across a set (Michael's rule for all board pedals). One setting has to serve every song in the set; only the footswitch changes.
- The bass drop-off on the repeats keeps a bass patch's low end clean under delay. Still keep Level low on bass.
- Keep Feedback below about 2 o'clock unless runaway oscillation is the point.
