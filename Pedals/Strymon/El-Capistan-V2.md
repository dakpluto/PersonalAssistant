# Strymon El Capistan V2

Tape echo pedal modeling three classic tape-delay head configurations (Fixed, Multi, and Single moveable head), each with its own set of secondary Mode options, plus a built-in spring reverb and tape-degradation controls (age, wow & flutter).

## Controls
- **Tape Age**: Simulates tape bandwidth/age — darker, narrower response as it's turned toward "older"
- **Wow & Flutter**: Amount of mechanical tape-speed fluctuation in the repeats
- **Repeats**: Number/amount of repeats, from a single echo up to self-oscillation
- **Time**: Delay time, interpreted differently depending on the selected Tape Head type
- **Mix**: Dry/echo balance; 50/50 at 3 o'clock
- **Spring Reverb**: Adds spring reverb to the signal without changing the dry or echo levels
- Secondary functions (accessed by holding a knob): **Tape Crinkle** (amount of tape irregularity), **Tape Bias** (tonal bias adjustment), **Low End Contour** (shapes low end of the repeats), **Boost/Cut** (±3dB level trim)

## Footswitches / Switches
- **Tape Head** (mini-toggle, 3-position): Fixed (single fixed head — vintage studio tape-delay style), Multi (two simultaneous heads — Roland Space Echo/Watkins Copicat style), or Single (one adjustable-position head — Echoplex style)
- **Mode** (mini-toggle, 3-position, meaning depends on Tape Head): on Fixed — Mode A/B/C select Head 1 (short, 1/16-note tap), Head 2 (medium, dotted-1/8 tap), or Head 3 (long, 1/4-note tap); on Multi — Mode A/B/C select which two heads combine (1&2, 2&3, or 1&3); on Single — Mode A/B/C select double-speed motor, normal-speed motor, or Sound-on-Sound
- **Tap footswitch**: Taps in tempo; hold for infinite repeats
- **Bypass footswitch**: Engages/bypasses the effect

## Notes for patch-building
- Fills the same DLY-slot role as the GP-5's own tape-delay algorithms but with a genuine multi-head architecture and a built-in spring reverb tail — good pick when a patch wants tape-style wow/flutter character the GP-5's onboard delay can't quite replicate.
- Because Tape Head and Mode are both fixed toggles (not footswitch-conditional), settle on one head/mode combination per static patch.
- Stereo in/out via TRS input (Class A JFET preamp) and two independent TS outputs; rear-panel switch sets mono (TS) or stereo (TRS) input handling.
- Power: 9VDC center-negative, 300mA minimum (supply not included).
