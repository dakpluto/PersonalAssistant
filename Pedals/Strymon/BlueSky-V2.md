# Strymon blueSky V2

Compact stereo reverb pedal offering three core reverb types (plate, room, spring) each with an optional shimmer/modulation layer — the V2 revision added dual independent stereo outputs, MIDI/USB-C, and an onboard Favorite-preset footswitch alongside the original's knob-driven simplicity.

## Controls
- **Decay**: Reverb tail length
- **Pre-Delay**: Time gap before the reverb onset appears after the dry signal
- **Mix**: Dry/wet balance; 50/50 around 3 o'clock
- **Low**: Dampens low-frequency content in the reverb
- **High**: Controls high-frequency content in the reverb
- **Shimmer**: Amount of pitch-shifted shimmer layered into the reverb (behavior depends on the selected reverb Type)

## Footswitches / Switches
- **Type** (mini-toggle, 3-position): Plate, Room, or Spring reverb algorithm
- **Mod** (mini-toggle, 3-position): Off, Light, or Deep modulation depth applied to the reverb tail
- **On/Off footswitch**: Engages/bypasses the effect
- **Favorite footswitch**: Recalls a saved preset vs. the live knob state

## Notes for patch-building
- Direct, simpler substitute for the GP-5's RVB slot when a straightforward plate/room/spring choice (with an optional shimmer layer) covers the need better than the GP-5's onboard reverb algorithms.
- Stereo in/out via a TRS input (Class A JFET preamp) and two independent TS outputs; rear-panel switch sets MONO or STEREO input handling.
- Has an EXP/MIDI jack and USB-C for expression pedal or MIDI control.
- Power: 9VDC center-negative, 300mA minimum (supply not included).
