# Boss PS-6 Harmonist

Intelligent pitch-shifter/harmonizer pedal offering four distinct effect modes — Harmony, Pitch Shifter, Detune, and Super Bend (S-BEND) — in one compact unit, with expression-pedal control available for real-time pitch manipulation.

## Controls
- **MODE knob**: Selects the effect type — Harmony, Pitch Shifter, Detune, or Super Bend (S-BEND)
- **KEY / FALL TIME knob**: In Harmony mode, sets the musical key (major/minor) used to generate correct harmony intervals; in Super Bend mode, this knob instead controls the pitch-bend descent (fall) speed
- **SHIFT knob**: Selects the specific pitch interval or harmony voicing within the chosen mode (e.g., 3-voice harmony, octave-up, fifth-down, detune amount)
- **BALANCE / RISE TIME knob**: In most modes, blends the dry signal against the shifted/harmonized voice(s); in Super Bend mode, this knob instead controls the pitch-bend ascent (rise) speed

## Footswitches / Switches
- Single pedal switch: engages/bypasses the effect, and (per mode) can trigger the Super Bend pitch sweep.
- CHECK indicator LED doubles as a battery-check light.
- EXP jack accepts an optional expression pedal (e.g., Boss FV-500L/H, Roland EV-5) for real-time control of pitch parameters — most useful for sweeping Super Bend mode by foot.

## Notes for patch-building
- Buffered bypass; place early-to-mid chain like other pitch/harmony effects — typically before heavy drive/distortion (harmony/pitch tracking degrades on a heavily saturated signal) though some players run Detune or light Harmony after drive for texture. Track clean-into-the-pedal when accurate tracking matters most.
- Harmony mode is the pick for diatonic two-voice harmony lines (needs correct KEY setting to stay in scale); Detune mode is a wide, chorus-adjacent thickening effect rather than a discrete harmony interval; Pitch Shifter mode gives fixed intervals (e.g., octave up, fifth down) for lead/texture tricks; Super Bend is a dramatic multi-octave pitch-sweep effect (whammy-style dive/rise), best used as a momentary/expressive effect rather than an always-on tone.
- Good substitute for a GP-5 patch's own pitch/harmony algorithm when a specific real-pedal harmony voicing or the Super Bend dive-bomb effect is wanted as a distinct, separately-switchable effect.
- Mono in, with OUTPUT A(MONO)/B jacks available for stereo spreading of the shifted voices if desired.
