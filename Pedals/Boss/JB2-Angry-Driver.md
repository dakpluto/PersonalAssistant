# Boss JB-2 Angry Driver

Collaboration pedal between Boss and JHS Pedals combining two full drive circuits in one enclosure: a Boss BD-2 Blues Driver circuit and a JHS Angry Charlie (high-gain, Marshall-esque) circuit, released for Boss's 40th anniversary in the compact pedal line. Can run either circuit alone, or combine them in series/parallel.

## Controls
- **Drive**: Dual-concentric knob — top half sets the JHS (Angry Charlie) circuit's drive, bottom half sets the Boss (Blues Driver) circuit's drive, fully independent
- **Tone**: Dual-concentric knob — top/bottom halves independently set tone for the JHS and Boss circuits respectively
- **Level**: Dual-concentric knob — top/bottom halves independently set output level for the JHS and Boss circuits respectively
- **Mode**: 6-position rotary selector choosing how the two circuits are engaged:
  1. JHS (Angry Charlie) circuit only
  2. Boss (Blues Driver) circuit only
  3. Footswitch toggles between the two circuits
  4. JHS circuit feeding into the Boss circuit (series)
  5. Boss circuit feeding into the JHS circuit (series)
  6. Both circuits run in parallel and mixed together

## Footswitches / Switches
- Single main footswitch for effect on/off (its exact behavior — which circuit(s) it engages/toggles — depends on the Mode setting above)
- Remote jack accepts an external footswitch for hands-free mode/circuit switching

## Notes for patch-building
- Effectively two drive pedals in one box: a smoother, mid-gain Blues Driver-style overdrive and a more aggressive, higher-gain Angry Charlie-style distortion, independently dialed in and selectable/combinable via the Mode switch.
- Because Mode is fixed by rotary selector (not footswitch-changeable mid-song in most modes), pick a Mode that matches the song's needs when building a static patch, or Mode 3 if the intent is a true two-voicing footswitch toggle.
- Typical placement: drive section of the chain — can function as a single flexible drive stage (one circuit chosen) or as a stacked rhythm/lead pair when run in series/parallel modes.
- Mono in/out.
