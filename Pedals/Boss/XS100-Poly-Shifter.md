# Boss XS-100 Poly Shifter

Flagship pitch-shifting "workstation" pedal (2025) — the larger, more powerful sibling of the XS-1. Adds an onboard expression pedal, an 8-octave shift range, 30 preset memory slots, and MIDI/USB connectivity on top of the same Adaptive Focus polyphonic shifting engine.

## Controls
- **Onboard expression pedal (rubber-capped, rocker style)**: Assignable to real-time pitch control — sweeping octave jumps, on/off effect switching, or subtle chorus-style detune shimmer, depending on assignment
- Additional shift/parameter controls for dialing in interval, balance, and detune settings (mirrors the XS-1's shift/balance/detune concept, expanded for the workstation format with the added preset system)

## Footswitches / Switches
- Footswitch(es) on the main unit for engaging effects/recalling presets
- Two external footswitch jacks for additional live-performance control
- 30 onboard preset slots recallable via footswitch/expression pedal
- MIDI I/O for external preset recall/control
- USB-C port for firmware updates

## Notes for patch-building
- This is a pedalboard "workstation" rather than a simple stomp — its scale (built-in expression pedal, 30 presets, MIDI) makes it best suited to boards built around it as a centerpiece pitch/shifting hub rather than a drop-in single-effect slot.
- Full analog dry-through path is provided alongside the processed signal, so the dry tone is unaffected structurally even when heavy pitch processing is engaged.
- Supports full-frequency range for both guitar and bass.
- Placement: like other pitch/shift effects, place before drive/distortion for the cleanest, most accurate tracking.
- Consider the XS-1 instead for a simpler, single-footswitch board slot when the full preset/expression/MIDI workstation feature set isn't needed.
