# Boss CH-1 Super Chorus

Stereo chorus pedal from Boss's compact "Super" series, built around four straightforward controls (Effect Level, EQ, Rate, Depth). Simpler than the CE-5 (single EQ knob instead of separate High/Low filters) but shares the same stereo A/B output architecture.

## Controls
- **E.LEVEL**: Mixing level of the effect (pitch-changing) sound against the normal signal — clockwise increases effect volume
- **EQ**: Tone of the effect sound — clockwise boosts higher frequencies, counterclockwise cuts them
- **RATE**: Speed of the chorus modulation — clockwise quickens, counterclockwise slows
- **DEPTH**: Depth of the chorus modulation — clockwise deepens the effect, counterclockwise creates the opposite (thinner) effect

## Footswitches / Switches
- Single pedal switch: turns the effect ON/OFF.
- CHECK indicator LED shows effect on/off state and doubles as a battery-check light.

## Notes for patch-building
- True stereo output (OUTPUT A/B): for mono output use OUTPUT A only (carries the mixed wet+dry signal). In stereo, OUTPUT A carries only the effect (pitch-changing) sound and OUTPUT B carries only the dry sound — the CH-1 uses a "space compounding" stereo system, so the perceived effect intensity varies with the physical distance between the two speakers/amps.
- Buffered bypass (Nominal I/O -20 dBu, 1 MΩ in / 1 kΩ out) — safe to place anywhere in a chain without signal loss concerns when bypassed.
- Simpler and cheaper than the CE-5; a good choice when only broad-strokes tone shaping (one EQ knob) is needed rather than independent high/low filtering.
- Standard modulation-block placement: after drive/distortion, before delay/reverb — same conceptual slot as a GP-5 MOD block or the CE-5.
- If a guitar with a hot/high-output pickup is run into a large stereo output, the sound can distort; lowering the EQ or Effect Level knob, or using a limiter, resolves it.
