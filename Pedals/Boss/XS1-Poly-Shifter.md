# Boss XS-1 Poly Shifter

Compact polyphonic pitch-shift pedal (2025) built around Roland/Boss's Adaptive Focus (AF) processing for glitch-free, natural-feeling polyphonic shifting — full chords track cleanly, not just single notes. Covers up to ±7 semitones or up to 3 octaves up/down.

## Controls
- **Shift (rotary)**: Dials in the pitch-shift interval — semitone steps and octave jumps
- **Balance**: Blends the dry (unaffected) signal against the pitch-shifted signal
- **Detune switch**: Sends the shifted voice up or down for a detune-style thickening effect

## Footswitches / Switches
- Single footswitch, with a **Toggle/Momentary switch**: Toggle mode latches the shift on/off like a normal effect; Momentary mode applies the shift only while the footswitch is held, for on-the-fly dive/rise effects.
- External footswitch jack: connecting an external footswitch (or two) allows recalling up to three custom setups.
- EXP jack: an expression pedal enables hands-free, sweeping real-time pitch bends.

## Notes for patch-building
- Polyphonic tracking (chords, not just single notes) is the headline feature — distinguishes it from older Boss pitch pedals (e.g., PS-6) that track best on single-note lines.
- Placement: like other pitch/shift effects, works best fed a clean, unprocessed signal — place before drive/distortion/fuzz rather than after.
- The Momentary switch mode makes this a strong "instant octave-up solo boost" or "drop tuning stab" tool without needing to re-engage/disengage the footswitch for a single hit.
- Works for both guitar and bass.
- Good substitute for a GP-5 patch's own pitch-shift algorithm whenever true polyphonic (chord-safe) shifting is needed, or when the momentary/toggle footswitch behavior is specifically wanted.
