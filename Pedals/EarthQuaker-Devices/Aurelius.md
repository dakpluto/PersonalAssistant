# EarthQuaker Devices Aurelius (Tri-Voice Chorus)

Three-mode modulation pedal covering vibrato, classic chorus, and Leslie-style rotary-speaker emulation from a shared Width/Rate/Balance control set. Note: despite the name suggesting otherwise, this is a modulation (chorus/vibrato/rotary) pedal, not a reverb — EarthQuaker's own product listing categorizes it as "Tri-Voice Chorus."

## Controls
- **Width**: Amplitude of the LFO — how wide the pitch modulation sweeps. In Rotary mode, lower settings accentuate lower "woofer" frequencies and higher settings accentuate upper "horn" frequencies (mimicking a Leslie's two-rotor behavior).
- **Rate**: Speed of the LFO/modulation.
- **Balance**: Function depends on mode — in Mode V (Vibrato/Chorus) it blends the amount of pitch modulation mixed with the dry signal (fully clockwise = pure pitch vibrato, no dry blend); in Mode R (Rotary) it sets the wet/dry balance, with clockwise producing a more pronounced, pulsing sub-frequency effect. (Mode C behavior is analogous to Mode V's blend function, voiced as a classic chorus.)
- **Mode switch (3-way: V / C / R)**: Selects Vibrato, Chorus, or Rotary Chorus voicing.

## Footswitches / Switches
- **Save/Recall footswitch**: Toggles between Live mode and Preset mode; accesses 6 programmable presets (LED color indicates which mode is active).
- **Expression jack**: TRS expression pedal or CV (0–3.3V) can take over Width, Rate, or Balance.

## Notes for patch-building
- Sits in the modulation slot, same functional role as the GP-5's MOD module — use Mode V for subtle chorus/vibrato thickening, Mode R when a patch wants a rotary-speaker/Leslie character (organ-like swirl) rather than a straight chorus.
- The 6-preset save/recall makes this a good pick when a song needs to switch between two very different modulation characters (e.g. subtle chorus for verses, full rotary swirl for a bridge) without re-dialing knobs mid-song — plan preset slots accordingly.
- Relay-based true bypass with Flexi-Switch technology (latching and momentary from the same switch). Mono in/out. 9V DC 2.1mm center-negative, 75 mA current draw.
