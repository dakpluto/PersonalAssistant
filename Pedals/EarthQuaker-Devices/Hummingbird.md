# EarthQuaker Devices Hummingbird (Repeat Percussion Tremolo, V4)

Tremolo pedal recreating the "repeat percussion" vintage amp-tremolo circuits of the 1950s-60s, capable of everything from classic warm pulse to fast, synth-like chopped textures.

## Controls
- **Depth**: Modulation intensity, from barely-there to full signal chop at maximum. At zero, the pedal effectively acts as a clean boost (no tremolo).
- **Rate**: LFO speed — clockwise faster, counterclockwise slower. Defeated (bypassed) when an expression pedal is connected to the expression jack, which takes over rate control.
- **Level**: Output volume, for unity gain or boosting/cutting through the effect.
- **Mode toggle (3-position)**: Selects the LFO speed range — slow, mid-tempo, or fast — that the Rate knob then sweeps within.

## Footswitches / Switches
- Single footswitch, relay-based true bypass with Flexi-Switch technology (latching or momentary/hold operation).
- Expression pedal input (1/4" jack) for real-time foot control of Rate; EarthQuaker recommends the Moog EP-2.

## Notes for patch-building
- Sits in the modulation slot of the chain, same role as the GP-5's own MOD tremolo algorithms — use this pedal when a more vintage "repeat percussion" amp-tremolo character is wanted over the onboard digital tremolo.
- Depth-at-zero-as-clean-boost is a real usable state, not just an "off" position — worth knowing if a patch wants a boost-only stage from this pedal without any chop.
- Momentary Flexi-Switch mode allows tremolo to be foot-triggered only while held down, useful for a hit/stutter effect distinct from a straightforward CTL on/off toggle.
- Mono in/out, true bypass.
