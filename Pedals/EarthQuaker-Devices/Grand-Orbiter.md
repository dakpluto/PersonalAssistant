# EarthQuaker Devices Grand Orbiter (Phase Machine, V3)

Fully analog, 4-stage OTA-based phaser that also does double duty as a vibrato/vibe effect. Known for a wide range from slow, mellow phase to fast, swirly jet-plane sweeps, plus a resonant filter mode with the LFO switched off.

## Controls
- **Sweep**: Sets the frequency peak of the phased signal — clockwise brightens, counterclockwise darkens.
- **Rate**: LFO speed — clockwise faster, counterclockwise slower.
- **Rate 1/2/3 toggle**: Selects the LFO range the Rate knob operates in — slow range, a fixed resonant-filter mode with the LFO off, or a fast range.
- **Depth**: Blends phased signal with dry for intensity; in Vibrato mode (dry signal removed) this instead acts as an output volume control.
- **Phase/Vibrato toggle**: Switches between standard phaser (dry + phased blend) and vibrato/vibe mode (dry signal removed).
- **Resonance**: Feedback/regeneration amount — more pronounced clockwise, subtler counterclockwise.

## Footswitches / Switches
- Single footswitch with Flexi-Switch technology — supports both latching (tap on/off) and momentary (hold-for-effect) operation.

## Notes for patch-building
- Mono in/out, 100% analog, true bypass.
- Sits in the modulation slot of the chain, typically after drive/amp and before delay/reverb — same placement logic as the GP-5's own MOD module (phaser algorithms).
- The Phase/Vibrato toggle makes this two distinct effects in one footprint: use it as a phaser substitute for GP-5 MOD, or flip to Vibrato mode for a pitch-wobble effect the GP-5's MOD/PRE section may not replicate as convincingly.
- Momentary Flexi-Switch operation is useful for a swell/hit effect triggered only while held, distinct from a normal on/off CTL toggle.
