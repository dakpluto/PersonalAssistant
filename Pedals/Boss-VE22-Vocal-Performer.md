# Boss VE-22 Vocal Performer

Vocal effects processor with harmony/doubling, an onboard looper, and a library of vocal-specific effects — not a guitar pedal. Built around three multi-function knobs (Harmony, Effect, Echo) that each open into deeper sub-parameters, aimed at solo singer-songwriters and singing guitarists/bassists who want studio-style vocal processing live.

## Controls
- **HARMONY**: Multi-function knob for the harmony/doubling engine — select a harmony type, set the song key, and adjust voicing and harmony level. Creates ensemble vocal sounds (one or more harmony voices layered with the lead vocal).
- **EFFECT**: Multi-function knob selecting from a library of 39 effect types, including compressor, EQ, delay, reverb, lo-fi, distortion, radio, and ring mod, plus other specialty/character effects.
- **ECHO**: Multi-function knob for delay/echo parameters run alongside the Effect block.
- **MIC SENS**: Input gain trim for the XLR mic input.
- **MEMORY**: Scrolls through and selects stored patches (99 user + 50 preset memories); press to confirm/recall.
- **PHONES/LINE**: Output level for the stereo PHONES/LINE OUT jack.
- Each multi-function knob (Harmony/Effect/Echo) can be clicked to turn that section on/off, or double-clicked to dive into its deeper sub-parameters via the MENU/EXIT buttons and UP/DOWN switches.

## Footswitches / Switches
- Three footswitches with large surfaces, operable by foot or hand. Function is customizable — typically used to engage/disengage effect blocks, step through memory patches, and control the onboard looper (record/overdub/play-stop/undo).
- HARMONY switch: toggles the harmony block on/off independent of the footswitches.
- PHANTOM switch: enables 48V phantom power on the XLR mic input for condenser mics.
- Supports external footswitches (Boss FS-5U, FS-6, FS-7) and expression pedals (Boss EV-30, FV-500L/H, Roland EV-5) via the CTL1,2/EXP jack for hands-free control of parameters or looper functions.

## Notes for patch-building
- This lives in the vocal chain (mic → VE-22 → PA/mixer/interface), separate from and parallel to the guitar/bass signal path through the GP-5 — it does not sit inline with a guitar patch's module order.
- Useful for a singing guitarist/bassist: pair a GP-5 guitar patch with a VE-22 vocal patch (harmony, doubling, reverb/delay on the voice) for a full-band-in-a-box live setup.
- Onboard looper (37 seconds) loops the vocal signal only, independent of any guitar looping.
- Quirks: XLR mic input needs the PHANTOM switch enabled for condenser mics; balanced XLR outputs can be configured as stereo, dual mono, or wet/dry + dry; USB-C enables direct recording/playback with a computer or mobile device.
