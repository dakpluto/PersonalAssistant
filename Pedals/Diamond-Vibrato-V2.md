# Diamond Vibrato V2

Analog pitch vibrato built around the MN3007 bucket-brigade chip, offering true (pitch-shifting) vibrato as well as chorus-like blended tones, with a footswitch-activated "doubler" for on-the-fly speed changes. V2 widens the speed/depth range over the original Vibrato.

## Controls
- **Speed**: Modulation rate, roughly 0.1–20 Hz.
- **Depth**: Intensity/width of the pitch modulation.
- **Level**: Output volume.
- **Chorus**: Blends dry signal back in with the modulated signal — fully counterclockwise is 100% wet true vibrato, fully clockwise blends toward a 50/50 chorus-like tone.
- **Jazz EQ (High-Trim) switch**: 3-position toggle shaping high end — Subtle High-Trim / No-Trim / More Trim — for darker "vintage" voicings vs. brighter response.

## Footswitches / Switches
- Single footswitch: standard bypass on/off. Holding it down engages the "doubler," doubling the vibrato speed while held (or latched on, depending on configuration). Holding the footswitch down at power-up toggles whether the doubler behaves as momentary (only while held) or latching (toggles on/off with a press-and-hold).

## Notes for patch-building
- Functions like the GP-5's MOD module (chorus/vibrato-family effect) but leans further toward true pitch-vibrato character than a typical chorus — use it when a patch wants an authentic vibrato wobble (pitch modulation) rather than the chorus module's pitch+delay blend.
- The Chorus knob's dry/wet blend means one pedal setting can cover both a subtle chorus-like shimmer and a full-throw vibrato warble depending on where it's set, useful if a patch only has one MOD-equivalent slot to spend.
- The doubler-on-hold behavior is a real-time performance feature (like a built-in speed-boost footswitch) — worth noting for full-board patches where the player wants a "kick it into a wilder wobble" moment, similar in spirit to a CTL-triggered parameter change, though this happens at the pedal itself rather than through the GP-5.
- Runs on 9–18V DC; some players prefer 9V for a "warmer, more colored" wobble and 18V for extra headroom — worth flagging as an optional tone tweak if the target power supply is switchable.
