# Way Huge Green Rhino Overdrive MkIV

Jeorge Tripps' Tube Screamer-derived overdrive, originally released in 1996 during Way Huge's first run (only 419 units made before the company closed in 1999) and prized enough as a discontinued pedal to command serious collector prices before Jim Dunlop revived the Way Huge brand. Tripps built more low end into the circuit than the 808 it was inspired by, giving it a thicker, less thin-sounding overdrive than a stock Tube Screamer. The current WHE207 MkIV is Dunlop's standard-production full-size version (a smaller "Smalls" MkV variant existed but is now discontinued/legacy).

## Controls
- **Volume**: Output level
- **Tone**: High-frequency contour
- **Drive**: Overdrive gain amount
- **100Hz**: Dedicated low-frequency shelf, ±12dB cut/boost
- **500Hz**: Dedicated mid-frequency shelf, ±12dB cut/boost

## Switches
- **Classic**: Bypasses the MkIV's added 100Hz/500Hz EQ stage, reverting to the simple three-knob Volume/Tone/Drive behavior and voicing of the original Green Rhino.

## Notes for patch-building
- Typical placement: drive stage, early in the chain — works both as a rhythm-tone overdrive into a clean amp and as a gain/sustain boost stacked in front of an already-distorted amp channel, per Dunlop's own description.
- The 100Hz/500Hz EQ pair is the key patch-building lever beyond the base TS-style drive/tone/volume set — use it to dial in extra low-end thump (a signature of this pedal vs. a stock Tube Screamer) or scoop mids for a tighter, more modern voicing; set the Classic switch on for a historically accurate vintage-Green-Rhino patch instead.
- Way Huge pedals of this era are described by reviewers as using quiet relay-based true-bypass switching; exact bypass implementation for the current Dunlop-era MkIV specifically wasn't independently confirmed against a manual, so treat as true bypass with high but not absolute confidence.
- Power: 9V battery or Dunlop ECB003 adapter / DC Brick family supplies; exact current draw not confirmed in research.
- Distinct from the (now legacy/discontinued) compact "Smalls" Green Rhino MkV, which replaced the fixed 100Hz/500Hz pair with a single internally-switchable Freq control plus a Curve control — don't confuse the two when sourcing a patch's exact knob layout.
