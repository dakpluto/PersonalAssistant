# Klon Centaur

Legendary "transparent" overdrive hand-built by Bill Finnegan between 1994 and 2008 (~8,000 made). **Vintage/discontinued — not currently manufactured or sold.** Included here as reference only; the current official production equivalent is the Klon KTR (see `Klon-KTR.md`). Original units now trade for extremely high used prices due to scarcity and reputation.

## Controls
- **Gain**: Overdrive/drive amount (dual-gang potentiometer in the original circuit)
- **Treble**: Active high-pass-style filter boosting/cutting frequencies above roughly 400Hz — shapes high-end presence rather than acting as a simple tone knob
- **Output**: Output level of the pedal

## Notes for patch-building
- Popularized the "transparent overdrive" concept — designed to add gain and harmonic content while leaving the underlying tone of the guitar/amp largely intact, rather than imposing its own strong voicing.
- Typical placement: first or second drive stage in the chain, often run as an always-on or boost-style pedal in front of an already-driven amp rather than as the primary distortion source.
- Buffered bypass (not true bypass) — the input buffer stays in the signal path even when the effect is off.
- Because this is a discontinued/unobtainable vintage unit, treat it as reference-only for tonal character (e.g. when a source describes a "Klon-y" tone) — for an actual current-production pick, use the Klon KTR entry instead.
