# MXR Phase 95 (M290)

Mini-format phaser that packs two of MXR's classic phase circuits — the two-stage Phase 45 and the four-stage Phase 90 — into a single Phase 90-sized enclosure with a mode switch to pick between them, plus a second switch that recreates the earliest "script logo" Phase 90 voicing.

## Controls
- **Speed**: Rate of the phase sweep, spec'd 0.125Hz to 10Hz — from slow, subtle shimmer to fast, swooshing warble.

## Switches
- **45/90**: Toggles between Phase 45 mode (two-stage phasing, red LED) and Phase 90 mode (four-stage phasing, blue LED) — the two underlying circuits the pedal combines.
- **Script**: Removes feedback from the circuit for a subtler, more vintage "script logo" sound (amber LED indicates engaged); disengaged, the pedal runs its default "block logo" voicing which uses feedback for a more pronounced, accentuated swoosh.

## Notes for patch-building
- Typical placement: modulation stage, after drive/distortion and before delay/reverb — same conceptual slot as the GP-5's MOD module.
- True bypass footswitch (blue LED indicates engaged); mono in/out.
- Cannot run on a 9V battery — requires a Dunlop ECB003 adapter or DC Brick/Iso-Brick-family supply, 8mA draw.
- Because 45/90 and Script are independent toggles, the pedal effectively offers four distinct phaser voicings (Phase 45 or Phase 90, each with or without Script's feedback-removed vintage character) from one Speed knob — worth specifying all three settings (Speed + both switches) precisely in a patch write-up rather than just "phaser on."
