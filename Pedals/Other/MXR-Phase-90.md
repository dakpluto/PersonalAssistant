# MXR Phase 90 (M101)

Classic single-knob analog phaser, one of the most recognizable stompboxes ever made (that orange enclosure). The current standard production model is the MXR M101 Phase 90 — a 4-stage optical phaser with one control. Notable current variants also sold by Dunlop/MXR include the Script Phase 90 (with LED) and Custom Shop Script Phase 90 reissues voiced to the earliest 1970s script-logo circuit, and the EVH Phase 90 signature pedal (Eddie Van Halen's script-logo-spec unit in a smaller enclosure); this entry covers the standard M101.

## Controls
- **Speed**: Sets the rate of the phase sweep — from slow, subtle shimmer to fast, swooshing warble

## Footswitches / Switches
- Single footswitch: engages/bypasses the effect (true bypass on the M101). Red LED indicates when the effect is engaged.

## Notes for patch-building
- One-knob simplicity by design — there's no depth/mix/feedback control to tweak, just Speed; the character is fixed by the circuit (4-stage phasing).
- True bypass — no signal coloration when off, but no buffer either; consider placement/cable length in a chain with other true-bypass pedals and long runs.
- Standard modulation-block placement in the signal chain: after drive/distortion, before delay/reverb — same conceptual slot as a GP-5 MOD block, alongside/instead of chorus or flanger.
- Mono only, single input/output.
- If a patch calls for the specific "script logo" vintage phaser voicing (slightly different sweep character than later block-logo circuits), note that as a variant choice — the script and Custom Shop Script versions use different internal component values than the standard M101.
