# Klon KTR

Official current-production Klon overdrive — the modern, PCB-built reissue of the original hand-built Klon Centaur (see `Klon-Centaur.md`), authorized and released by original designer Bill Finnegan. Carries forward the same "transparent overdrive" design goal in a more affordable, mass-producible enclosure.

## Controls
- **Gain**: How much distortion the unit generates on its own
- **Treble**: High-frequency response, capable of subtle gradations
- **Output**: Output level of the pedal

## Switches
- **Buffer switch** (side-mounted, labeled "Almost Always Better" / "Almost Always Worse"): Toggles between the pedal's buffered output and a true-bypass output, letting the player choose whether the KTR's buffer stays in the signal path when the effect is bypassed.

## Notes for patch-building
- Same transparent-boost/overdrive role as the original Centaur: adds gain and harmonic richness without heavily recoloring the underlying amp tone — works well as an always-on push into a clean-to-edge-of-breakup amp setting, or as a mid-chain boost ahead of a higher-gain distortion stage.
- Typical placement: early in the drive stage of the chain, before fuzz/high-gain distortion pedals.
- Mono in/out. The buffer switch is a genuine practical decision point for patch-building: set to buffered when the KTR needs to condition a long cable/pedal run even while off, or true bypass when minimizing coloration on an otherwise buffer-heavy board.
- Unlike the original Centaur, this is a currently purchasable, verifiable-spec pedal — safe to use as the "go-to Klon" pick for new patches.
