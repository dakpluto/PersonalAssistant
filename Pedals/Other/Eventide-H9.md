# Eventide H9 Harmonizer (Gen 2)

Stereo multi-effect algorithm workstation, not a single fixed effect — the compact, one-box distillation of Eventide's entire effects catalog. The original H9 Harmonizer (2013) was officially retired in 2026 after 13 years and replaced by the **H9 Harmonizer Gen 2**, rebuilt on the same modern processing platform as the larger H90 Harmonizer and now carrying the H90's full algorithm library. The H9 Gen 2 is the compact/single-engine counterpart to the H90: H90 runs two algorithms simultaneously on a dual-core engine with a larger, dual-footswitch-plus-expression-oriented control surface (and a higher price), while H9 Gen 2 runs one algorithm at a time on a single-core version of the same architecture in a smaller pedalboard footprint — both are current production, with the H9 Gen 2 as the compact-format flagship.

## Controls
- **3 Quick Knobs**: assignable to an algorithm's primary parameters for real-time hands-on tweaking
- **2 programmable footswitches**: behavior is configurable per-preset via Perform Mode (tap tempo, active/bypass, momentary active, or an assigned HotSwitch)
- **HotKnob**: a macro control that can sweep multiple underlying parameters at once from a single physical knob motion
- **HotSwitch**: a macro control (up to 2 independent instances) that jumps multiple parameters between two states from a single footswitch tap
- **2.5" display** with button-pad navigation across four workflow modes: Select (browse by effect type/algorithm), Perform (live footswitch/knob customization), Presets (preset browsing/recall), and Parameters (deep per-algorithm editing)

## Notes for patch-building
- Functions as a whole effects section rather than one module — a single H9 preset can stand in for MOD, DLY, and RVB simultaneously (and DST/PRE via its Distortion category), so when substituting it into a patch, note which category/algorithm is covering which GP-5 module role.
- 74+ algorithms across 9 categories: Granular, Harmonizer+Vocals, Delay, Reverb, Harmonizer (pitch-shifting, using Eventide's SIFT polyphonic pitch-tracking), Modulation, Distortion, Synth, and Looper/Multi-FX — ships with 1,000+ factory presets.
- Dual mono 1/4" TS in/out supporting true stereo, Wet/Dry/Wet, and Pre/Post routing configurations — worth noting explicitly in a patch write-up since the routing mode changes how it integrates with the rest of a stereo or mono board.
- Connectivity: 5-pin MIDI In/Out, USB-C (for the Eventide Control desktop/mobile app — firmware updates, preset management, routing/MIDI mapping, User List import/export), 1/4" TRS expression pedal input, and an auxiliary switch input for 1-3 external footswitches; Bluetooth support was announced as forthcoming at Gen 2 launch.
- "Seamless spillover" between presets (trails/tails continue ringing out through a preset change) is a named feature — relevant for delay/reverb-heavy patches where a hard cutoff on preset change would be undesirable.
- Because it's a menu-driven, preset-based workstation rather than a fixed set of knobs, an H9-based patch write-up should name the specific algorithm and preset (or the exact parameter values if hand-edited) rather than describing settings the way a simple 3-knob pedal's controls would be described.
