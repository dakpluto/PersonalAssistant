# Hologram Electronics Chroma Console

Stereo multi-effect workstation, not a single fixed effect. Twenty algorithms are organized into four reorderable modules — Character (drive/fuzz/swell), Movement (modulation/pitch), Diffusion (reverb/delay/granular), and Texture (filter/lo-fi/glitch) — and any module can be placed anywhere in the signal chain.

## Controls
- **Per-module knobs**: Each of the first three modules (Character, Movement, Diffusion) has two knobs controlling that module's primary parameters; the Texture module has one parameter knob. A shared knob above the modules sets global wet/dry mix.
- **Algorithm-select buttons**: One button beneath each module's knobs; pressing it steps through that module's five algorithms in turn (the pedal is heard cycling through each one on the way to the selected algorithm), and the button lights a distinct color per algorithm.
- **Secondary knob functions**: Each knob has a second parameter reachable via button-held combinations, labeled on the panel's control strip.

## Footswitches / Switches
- **Bypass footswitch**: Standard engage/bypass, with a "Dual Bypass" option that can be configured to switch off only a chosen subset of the four modules rather than the whole unit.
- **Tap footswitch**: Tap tempo for time-based/modulation effects; also used to trigger the CAPTURE looper/sustainer feature.

## Notes for patch-building
- Functions as a whole effects section rather than one module — a single Chroma Console can stand in for MOD, DLY, and RVB simultaneously (and even DST/PRE via the Character module), so when substituting it into a patch, note which of its modules is covering which GP-5 module role.
- The Diffusion module's Space and Collage algorithms are the closest analog to the GP-5's RVB/DLY — Space is a conventional-to-huge reverb (with a Drift control for pitch-modulated shimmer), Collage is a granular/glitchy delay with pitch bends, well beyond what the GP-5's own DLY can do.
- True stereo in/out (mono-input-to-stereo-output capable), MIDI In/Out/Thru with clock sync over DIN and USB-C, and an expression pedal input mappable to any control — worth noting if a patch calls for expression-controlled morphing. Stores 80 onboard presets.
- CAPTURE is a 30-second ephemeral looper that can be placed pre- or post-effects — a live-performance tool, not something a static patch spec can represent.
