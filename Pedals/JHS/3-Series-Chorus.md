# JHS 3 Series Chorus

Compact analog-voiced chorus/vibrato in JHS's $99 3 Series line, covering everything from subtle doubling to deep, seasick modulation.

## Controls
- **Volume**: Output level of the effect
- **Rate**: Speed of the modulation
- **Depth**: Intensity of the modulation
- **Vibe toggle**: Down is standard chorus (modulated signal blended with dry); up removes the dry signal for true pitch vibrato

## Notes for patch-building
- Rate + Depth together cover subtle "widening" chorus through heavy, warbly modulation
- Vibe (up) position is a true vibrato, not chorus — useful for a second distinct MOD-slot flavor without adding a pedal
- Mono in/out, 9V DC center-negative (70mA draw), single footswitch on/off with status LED, true bypass
