# JHS Bonsai

Nine-in-one Tube Screamer-family overdrive — a rotary Mode selector switches between component values recreating nine historical Screamer-derived circuits, from the original OD-1 through several TS variants to boutique mods, in one enclosure.

## Controls
- Standard Drive/Tone/Volume-style controls for the selected Mode (exact per-mode knob behavior varies slightly since some modes, like OD-1, don't use the Tone control the same way as the others).

## Footswitches / Switches
- **Mode** (9-position rotary selector): Selects between nine Tube Screamer-lineage circuits:
  1. **OD-1 (1977)** — brighter, somewhat higher gain than later Screamers; doesn't use Tone the same way as the rest
  2. **TS808 (1979)** — the classic low-gain grind with the signature mid-bump
  3. **TS9 (1982)** — similar to TS808 but brighter, pushed low-mids (the "SRV" voicing)
  4. **MSL "Metal Screamer" (1985)** — higher gain, more low end
  5. **TS10 (1986)** — bluesy, lower-gain, crisper (the "John Mayer" voicing)
  6. **Exar OD-1 (1989)** — Polish-made variant, slightly higher gain and more transparent
  7. **TS7 +Mode (1999)** — the highest-gain mode in the Bonsai
  8. **Keeley Mod Plus (2002)** — Robert Keeley's mod: tighter, quieter, smoother mids/highs, more bass
  9. **JHS Strong Mod (2008)** — JHS's own mod: cleaner with a strong power boost
- Single footswitch, true bypass.

## Notes for patch-building
- Mode is a fixed rotary choice per patch, not footswitch-toggleable — pick the Screamer variant matching the target tone (TS808/TS9 for the classic mid-forward overdrive-into-amp sound, MSL/TS7+ for higher-gain needs, Keeley Mod Plus/JHS Strong Mod for cleaner boost-forward voicings).
- Same drive-pedal role as any Tube Screamer-family box: low-to-medium-gain, mid-pushing, designed to drive an already-set-up amp rather than fully distort on its own.
- Typical placement: first or second drive stage in the chain, ahead of higher-gain distortion/fuzz.
- True bypass, mono in/out, standard 9V DC negative, 20mA draw.
