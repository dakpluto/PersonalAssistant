# JHS Morning Glory Clean

Low-gain variant of JHS's Morning Glory overdrive, adding a parallel studio-grade clean-blend circuit so the drive signal can be mixed against a fully clean path — usable either as a subtle overdrive with adjustable clean blend, or, with Clean maxed, as a pure clean volume boost.

## Controls
- **Volume**: Overall output level, set in conjunction with Drive and Clean
- **Clean**: Blends between the original Morning Glory drive voicing (full counterclockwise) and a fully clean signal (full clockwise)
- **Drive**: Saturation amount — designed to be run high, with Clean used to dial back to taste
- **Tone**: Classic Morning Glory tone stack, affects only the drive path — counterclockwise for warmth, clockwise for clarity

## Notes for patch-building
- Doubles as a clean boost: set Clean fully clockwise and raise Drive for pure volume boost with no overdrive clipping — useful for a solo-boost patch role without needing a second dedicated boost pedal.
- Lower-gain, more transparent than the standard Morning Glory (V4) — suited to edge-of-breakup rhythm tones or as an always-on amp-pushing drive.
- Typical placement: first/low-gain drive stage of the chain.
- Silent buffered bypass switching. Mono in/out, ±9V dual-supply-capable, 9V DC center negative, 60mA — do not exceed 9V.
