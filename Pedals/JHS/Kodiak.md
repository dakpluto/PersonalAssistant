# JHS Kodiak

**Not an overdrive/distortion pedal** — the Kodiak is a tap-tempo tremolo, built around classic Vox- and blackface-Fender-style tremolo voicings with modern additions (four waveforms, subdivisions, tap tempo/expression jack). Part of JHS's tap-tempo modulation series.

## Controls
- **Volume**: Overall output level; because it sits before the tremolo stage, can double as a clean boost/preamp when Mix is fully down.
- **Speed**: Tremolo rate, manually set or synced via tap tempo.
- **Mix**: Tremolo depth/wetness, from fully clean (dry) to fully wet.
- **Ratio**: Note subdivision relative to the tapped tempo — quarter notes, eighth notes, triplets, or sixteenth notes.
- **Wave**: Waveform shape, four options:
  - **Sine**: classic, smooth amp-like tremolo
  - **Rhythmic**: syncopated, pattern-based pulse
  - **Square**: hard-edged, choppy on/off tremolo
  - **Ramp**: asymmetric, warbly sawtooth-like pulse

## Footswitches / Switches
- **Tap/Exp toggle**: Switches the side jack between tap-tempo input and expression-pedal input.
- **Tap/Exp jack**: Accepts an external tap footswitch (to set Speed by tapping) or an expression pedal (to control Speed or Mix in real time, depending on implementation).
- Single main footswitch, on/off.

## Notes for patch-building
- Since this isn't a drive pedal, don't slot it where the brief description ("overdrive/distortion — verify actual circuit") might suggest; use it in the modulation section of a chain instead, typically after drive/distortion and before or after delay depending on desired interaction.
- Wave choice is the main character decision — Sine for vintage amp-style trem, Square for choppy/stuttering effects, Ramp/Rhythmic for more rhythmic, syncopated textures.
- Mono in/out, standard 9V DC negative, 10mA draw.
