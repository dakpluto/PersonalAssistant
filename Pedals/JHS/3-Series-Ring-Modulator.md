# JHS 3 Series Ring Modulator

Dual-mode ring modulator in JHS's $99 3 Series line, switching between a mode inspired by the discontinued Way Huge Ringworm and a mode inspired by the classic Green Ringer octave-up circuit.

## Controls
- **Blend**: Mixes the ring-modulated signal against the dry signal
- **Frequency**: Speed of the ring modulator's oscillator
- **Tweak**: Function depends on mode — in Earworm mode, introduces an auxiliary LFO adding wobble/movement; in Green Lantern mode, blends in the wave-rectified octave-up effect
- **Mode toggle**: Down is Earworm mode (Way Huge Ringworm-inspired); up is Green Lantern mode (Green Ringer-inspired, natural-sounding octave effect alongside the ring mod)

## Notes for patch-building
- Green Lantern mode (toggle up) is the more musical/usable option for a subtle octave-up sparkle; Earworm mode (toggle down) is the more classic bell-like/metallic ring-mod texture
- Extreme Frequency + Blend settings get atonal fast — dial back for a usable effect in a full-band mix
- Mono in/out, 9V DC center-negative (65mA draw), single footswitch on/off with status LED, true bypass
