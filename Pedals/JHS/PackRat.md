# JHS PackRat

Nine-in-one ProCo RAT-style distortion — a rotary Mode selector physically rewires the internal clipping/filter circuitry between values matching nine historical RAT variants (official and boutique), rather than modeling them digitally.

## Controls
- **Distortion**: Gain/distortion amount.
- **Filter**: Low-pass filter — brightens or darkens the tone.
- **Volume**: Overall output level.

## Footswitches / Switches
- **Mode** (9-position rotary selector): Physically switches the RAT clipping circuit between nine variants:
  1. **OG v1 (1979–1983)** — original "Fringe Logo" RAT; Tone control increases treble clockwise
  2. **White Face v3 (1984–1986)** — smaller enclosure, reverse-oriented filter response
  3. **Turbo v5 (1989)** — first RAT to use LED clipping diodes instead of silicon
  4. **BRAT v6 (1997)** — budget model, adds an input buffer and softer clipping
  5. **Dirty v7 (2004)** — germanium diode clipping, maximum saturation/fuzz-like
  6. **LA (1986)** — Ibanez 10-Series-style variant, op-amp rail clipping with no diodes
  7. **Landgraff MO'D (1999)** — point-to-point boutique distortion design
  8. **Caroline (2010)** — "Wave Cannon"-derived circuit
  9. **JHS Mode** — JHS's own take, based on a vintage small-box RAT
- Single footswitch, true bypass.

## Notes for patch-building
- Also sold in a **White** colorway — identical circuit and controls to the standard black PackRat, cosmetic difference only.
- Mode is a fixed rotary choice per patch (not footswitch-toggleable), so pick the RAT variant that matches the target tone before finalizing the patch — Dirty v7 and Turbo v5 lean into heavier fuzz-adjacent territory, OG v1/White Face v3/BRAT v6 are more classic mid-gain RAT distortion, LA/Landgraff/Caroline are boutique-flavored variations.
- Typical placement: main distortion stage of the chain, ahead of the amp; Filter knob is the primary brightness/darkness shaping tool across all nine modes.
- True bypass, mono in/out, standard 9V DC center-negative, 100mA draw.
