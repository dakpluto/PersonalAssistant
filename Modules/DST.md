# DST Module - Overdrive, distortion, and fuzz effects

## Green OD - Based on the legendary Ibanez TS-808 Tube Screamer pedal
- Gain: control the overdrive amount (1-100)
- Tone: Controls the effect tone (1-100)
- VOL: Controls the effect output (1-100)

## Yellow OD - Based on the Boss OD-1 Pedal with Asymmetrical clipping
- Gain: control the overdrive amount (1-100)
- VOL: Controls the effect output (1-100)

## Super OD - Based on the Boss SD-1 Pedal with Asymmetrical clipping
- Gain: control the overdrive amount (1-100)
- Tone: Controls the effect tone (1-100)
- VOL: Controls the effect output (1-100)

## SM Dist - Based on the Boss DS-1 Pedal with Hard Clipping
- Gain: control the Distortion amount (1-100)
- Tone: Controls the effect tone (1-100)
- VOL: Controls the effect output (1-100)

## Plustortion - Based on the MXR M104 Distortion + with Germanium soft clipping
- Gain: control the Distortion amount (1-100)
- VOL: Controls the effect output (1-100)

## La Charger - Based on the MI Audio Crunch Box Distortion Pedal
- Gain: control the Distortion amount (1-100)
- Tone: Controls the effect tone (1-100)
- VOL: Controls the effect output (1-100)

## Darktale - Based on the ProCo Rat Distortion early LM308 OP-amp version
- Gain: control the Distortion amount (1-100)
- Filter: Counterclockwise Controls the effect tone (1-100)
- VOL: Controls the effect output (1-100)

## Sora Fuzz - Based on the Sola Sound Tone Bender fuzz Pedal
- Fuzz: control the gain amount (1-100)
- VOL: Controls the effect output (1-100)

## Red Haze - Based on the Dallas-Arbiter Fuzz Face fuzz pedal
- Fuzz: control the gain amount (1-100)
- VOL: Controls the effect output (1-100)

## Bass OD - An overdrive effect designed for bass.
- Gain: control the Distortion amount (1-100)
- Blend: Controls the Wet/Dry Signal Ratio (1-100)
- VOL: Controls the effect output (1-100)
- Bass: Controls the Bass tone (1-100)
- Treble: Controls the Treble tone (1-100)
