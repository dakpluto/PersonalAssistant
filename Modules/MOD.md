# Mod Module - Modulation effects (Chorus, Flanger, Phaser, Vibrato, Tremelo)

## A-Chorus - Chorus - Based on Arion SCH-1 Chorus Pedal 
- Depth: Controls the chorus depth (1-100)
- Rate: Controls the chorus rate (0.10Hz-10.00Hz)
- Tone: Controls the effect tone (1-100)

## B-Chorus - Chorus - Based on Boss CEB-3 for Bass Guitar
- Depth: Controls the chorus depth (1-100)
- Rate: Controls the chorus rate (0.10Hz-10.00Hz)
- VOL: Controls the output volume (1-100)

## Jet - Flanger - Classic Flanger Effect
- Depth: Controls the flanger depth (1-100)
- Rate: Controls the flanger rate (0.10Hz-10.00Hz)
- P.Delay: Controls the pre delay time (1-100)
- F.Back: Controls the amount of feedback (1-100)

## N-Jet - Flanger - Flanger effect with negative feedback
- Depth: Controls the flanger depth (1-100)
- Rate: Controls the flanger rate (0.10Hz-10.00Hz)
- P.Delay: Controls the pre delay time (1-100)
- F.Back: Controls the amount of feedback (1-100)

## O-Phase - Phaser - Based on MXR M101 Phase 90
- Rate: Controls the effect speed (0.10Hz-10.00Hz)

## M-Vibe - Phaser - Based on Voodoo Lab Micro Vibe
- Depth: Controls the effect depth (1-100)
- Rate: Controls the effect speed (0.10Hz-10.00Hz)

## V-Roto - Vibrato - Based on BBD Blue Vibrato 
- Depth: Controls the effect depth (1-100)
- Rate: Controls the effect speed (0.10Hz-10.00Hz)

## Vibrato - Vibrato - Classic Vibrato Effect
- Depth: Controls the effect depth (1-100)
- Rate: Controls the effect speed (0.10Hz-10.00Hz)
- VOL: Controls the output volume (1-100)

## O-Trem - Tremolo - Based on Demeter TRM-1 Tremulator 
- Depth: Controls the tremolo depth (1-100)
- Rate: Controls the tremolo speed (0.10Hz-10.00Hz)

## Sine Trem - Tremolo - Sine tremolo waveform 
- Depth: Controls the effect depth (1-100)
- Rate: Controls the effect speed (0.10Hz-10.00Hz)
- VOL: Controls the output volume (1-100)

## Bias Trem - Tremolo - Bias tremolo waveform 
- Depth: Controls the effect depth (1-100)
- Rate: Controls the effect speed (0.10Hz-10.00Hz)
- VOL: Controls the output volume (1-100)
- Bias: Adjust the offset change of the waveform (1-100)
